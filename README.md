# Refridge

Sharing resources, memories, and secret receipts - Refridge focuses on bringing kitchens together to enhance social and physical well-being through nutrition.

## Build and run

Requires Node.js 22.12+.

```sh
npm ci
cp .env.example .env
npm run build
npm start
```
